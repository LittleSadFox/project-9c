# Errors — 2026-10-22

## 1. Mac sync_volume multipart SignatureDoesNotMatch

- Time (UTC): 2026-10-22
- Where: Mac / volume S3
- Symptom: Upload of a ~40MiB golden video failed with `CreateMultipartUpload` `SignatureDoesNotMatch`.
- Cause: AWS CLI `s3 cp` starts multipart above 8MB. Runpod S3 rejects that path. A single `PutObject` works.
- Next action: Use `aws s3api put-object`. Pin `s3.multipart_threshold` to 128MB in a temp AWS config. Do not use `aws s3 cp`.

## 2. Terminate stamp symlink and volume hook

- Time (UTC): 2026-10-22
- Where: review
- Symptom: A planted stamp symlink or a volume `CC_TERMINATE_STAMP_DIR` could skip terminate.
- Cause: The stamp write followed symlinks. The test hook had no path limit.
- Next action: Write stamps with `O_NOFOLLOW` / `O_EXCL`. Refuse a volume stamp dir. Keep an empty `RUNPOD_POD_ID` on the terminate path.
